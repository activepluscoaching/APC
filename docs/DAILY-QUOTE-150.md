# আজকের অনুপ্রেরণা — ডেইলি কোট (v150)

শিক্ষার্থীর হোম পাতায় **আজকের ক্লাস** ও **দ্রুত সেবা (Quick Menu)**-এর মাঝখানে
একটি ছোট উদ্ধৃতি-কার্ড। এটি অন্য কোনো পাতা, প্যানেল, ডেটা বা সিঙ্কে হাত দেয় না।

## কীভাবে কাজ করে

| বিষয় | সিদ্ধান্ত |
| --- | --- |
| অবস্থান | `#homeView` → `.student-home-overview` → `আজকের ক্লাস` → `#dailyQuoteCard` → `#studentServices` |
| নির্বাচন | `quoteDayNumber(quoteDateKey()) % library.length` — তারিখভিত্তিক, নির্ধারিত, কোনো র‍্যান্ডম নয় |
| দিন বদল | ঢাকা সময়ে (`Asia/Dhaka`) দিন বদলালে নতুন সূচক; দিনের মাঝখানে কখনো বদলায় না |
| অনলাইন | ফোন চালু হলে `assets/daily-quotes.json` একবার ব্যাকগ্রাউন্ডে পড়া হয় (দিনে একবার), সফল হলে ক্যাশে জমা হয় |
| অফলাইন | কার্ড আগেই ভরা থাকে: ক্যাশে থাকলে তা, নাহলে অ্যাপের ভেতরের ৩০টি বাঁধাই তালিকা |
| ব্যর্থতা | নেট নেই, ৪০৪, ভাঙা JSON, খালি ফিড, ঝুলে থাকা অনুরোধ (৪ সেকেন্ডে abort) — সবই চুপচাপ উপেক্ষা করা হয়; কোনো এরর, স্পিনার, খালি বক্স বা রিট্রাই নেই |
| ব্যবহারকারীর কাজ | নেই। কোনো বাটন, টোস্ট বা "বুঝেছি" নেই — বাক্যটি নিজে থেকেই আজকের বাক্য |
| স্টোরেজ | একটিমাত্র ব্যক্তিগত কী `activePlus.dailyQuote.v1`; অন্য কোনো রেকর্ড পড়া/বদল/মোছা হয় না |
| অফলাইন শেল | `sw.js` `CACHE_VERSION 150`; শেলে `js/daily-quote.js` ও `assets/daily-quotes.json` যোগ হয়েছে |

## ডেটা

- **ফিড:** `assets/daily-quotes.json` — `{ version, updatedAt, quotes:[{ id, text, author }] }`।
  পাঠানো ২৭টি বাক্য (Q-110 … Q-115, Q-200 … Q-220) অ্যাপের ভেতরের তালিকার সঙ্গে
  মিলিয়ে বাদ দেওয়া হয়েছে, তাই একই বাক্য দুবার আসে না।
- **ভেতরের তালিকা:** `js/daily-quote.js` → `BUILT_IN_QUOTES` (৩০টি), অ্যাপ অফলাইনেই কাজ করে।
- **ক্যাশ:** `{ version, dateKey, quote, quotes, fetchedAt, updatedAt }`; ভাঙা বা অপরিচিত রেকর্ড
  পড়ার সময় খালি ধরা হয়, কখনো ব্যতিক্রম তোলে না, কখনো মুছে ফেলা হয় না।

## ফাইল

- `js/daily-quote.js` — রোটেশন, ক্যাশ, ফিড পার্সার, `initDailyQuote()`
- `assets/daily-quotes.json` — ঐচ্ছিক অনলাইন ফিড
- `index.html` — কার্ড ও Quick Menu-র নতুন ক্রম
- `css/ui-wallet.css` — কার্ডের চেহারা ও তিনটি স্ক্রিন-মাপের কম্প্যাকশন
- `tests/daily-quote.test.mjs` — ১০টি টেস্ট (অবস্থান, রোটেশন, অফলাইন ব্যর্থতা, স্টোরেজ নিরাপত্তা, CSS চুক্তি)

খালি-রুটিন ও ছোট ফোনে ~৪০px) এবং CSS চুক্তি টেস্টে সেটি আটকে রাখা হয়েছে।
